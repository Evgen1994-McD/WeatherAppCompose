# 🌤️ Weather App Compose

Простое и элегантное приложение для просмотра погоды, построенное на **Jetpack Compose** с использованием современных архитектурных принципов.

## 📱 Описание

Приложение позволяет пользователям получать актуальную информацию о погоде в любом городе мира. Использует API WeatherAPI для получения метеорологических данных с высокой точностью.

### ✨ Основные функции

- 🔍 **Поиск погоды** - температура и состояние в любом городе
- 📅 **Прогноз по дням** - детальный прогноз на 10 дней вперед
- ⏰ **Прогноз по часам** - почасовая погода на выбранный день
- 🔄 **Обновление данных** - актуальная информация одним нажатием
- 🖼️ **Мини-иконки** - красивые иконки погодных условий
- 🎨 **Современный UI** - интуитивный интерфейс на Jetpack Compose

## 🏗️ Архитектура

Проект построен по принципам **MVVM** и **Clean Architecture**:

```
📁 app/src/main/java/com/example/weatherappcompose/
├── 🗂️ data/                    # Data Layer
│   ├── 📡 datasource/         # WeatherRemoteDataSource
│   ├── 🔄 mapper/             # WeatherMapper  
│   └── 🗃️ repository/         # WeatherRepositoryImpl
├── 🎯 domain/                 # Domain Layer
│   ├── 📊 models/            # WeatherModel
│   ├── 🔌 repository/        # WeatherRepository
│   └── ⚙️ usecase/           # WeatherUseCases
├── 🎨 presentation/           # Presentation Layer
│   ├── 🖼️ ui/                # WeatherScreen, WeatherList
│   └── 🧠 viewmodel/         # WeatherViewModel
├── 💉 di/                    # Dependency Injection
└── 🎨 ui/theme/              # UI темы
```

### 🛠️ Технологический стек

- **Jetpack Compose** - современный UI toolkit
- **MVVM** - архитектурный паттерн
- **Clean Architecture** - чистая архитектура
- **Hilt** - dependency injection
- **Coroutines** - асинхронное программирование
- **StateFlow** - реактивное программирование
- **Coil** - загрузка изображений
- **Volley** - сетевые запросы

## 🚀 Установка и запуск

### Предварительные требования

- Android Studio Arctic Fox или новее
- Android SDK API 29+
- Kotlin 1.8+

### Шаги установки

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/yourusername/WeatherAppCompose.git
   ```

2. **Откройте проект в Android Studio**
   - File → Open → выберите папку проекта

3. **Настройте API ключ** (опционально)
   - В файле `WeatherRemoteDataSource.kt` замените API ключ на свой
   - Получите бесплатный ключ на [WeatherAPI.com](https://www.weatherapi.com/)

4. **Запустите приложение**
   - Подключите устройство или запустите эмулятор
   - Нажмите Run или используйте `Ctrl+R`
